# Suggested data and code availability statement

Selected method code and a synthetic example supporting the implementation of
DCG-CAD are available at the project repository. The release includes the
dynamic design-state representation, evidence-governed orchestration,
validation and repair mechanisms, CAD operation interfaces, and an offline
reproducible example. The expanded engineering dataset and proprietary CAD
assets are not part of this release. Aggregate results and task-level reporting
needed to interpret the experiments are provided in the article and its
supplementary materials.

Replace “the project repository” with the final archived release URL or DOI
after the package has been uploaded and versioned.
